# Block Blitz

An ad-free block puzzle for Margot and Manon. Drag blocks onto the 8×8 board; full rows and columns clear.

- Two looks: ✨ Sparkle (Jessica's voice) and 🦇 Nevermore (a deadpan gothic voice).
- Each player has her own profile and best score, saved on the iPad and in Firebase (`wcp/BB<name>`).
- No ads, no links out, no tracking. Sounds, voices and music made once with ElevenLabs (`python3 make_audio.py`).
